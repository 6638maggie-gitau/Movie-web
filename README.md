# 🎬 Movie Web

Movie Web is a modern movie discovery web application built with React and Tailwind CSS.  
It allows users to browse trending movies and search for any movie in real time using the TMDB API.

---

## ✨ Features

- 🔥 Trending & popular movies display  
- 🔍 Real-time movie search  
- 🎞️ Dynamic movie cards from API  
- 📱 Fully responsive design (mobile-first)  
- ⚡ Fast and smooth user experience  

---

## 🧠 Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)
- TMDB API (The Movie Database)

---
